# Carlo Sorosina — Sito ufficiale

Sito ufficiale di **Carlo Sorosina**, scrittore dei piccoli gesti, della memoria e delle tracce che il tempo lascia nelle persone e nei luoghi.

Il repository contiene i file e le risorse del sito autore. Il sito presenta l'autore, le opere pubblicate e i contenuti relativi al suo percorso letterario.

**Sito online:**

## Struttura del repository

Il progetto comprende:

- Pagine HTML del sito autore.
- Immagini e risorse grafiche.
- `sitemap.xml`, per la struttura delle URL del sito.
- `robots.txt`, con le indicazioni per i crawler.
- `llms.txt`, documento di orientamento per i sistemi basati su modelli linguistici.

## Pubblicazione

Il sito è pubblicato tramite **GitHub Pages** e viene aggiornato progressivamente in relazione alle attività e alle pubblicazioni dell'autore.
